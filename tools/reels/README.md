# Reels-verktyg (MASKINHALLEN)

- `auto2.py <ut-mapp> <frö> [plastik|hardgroove]`: automatisk reel, 16 takter. Musik av BETONG-kitets ljud,
  ett klipp per takt mellan maskinerna (videor + skärmbilder), zoompuls på kicken, blixt vid nya avsnitt,
  ljudets filter följer rörelsen i bilden. Nytt frö = ny låt och ny klippordning.
- `make.py`: 15-sekunders TikTok-videor per maskin.
- `reel2.py`: 30-sekunders reels av egna skärminspelningar (en sammanhängande tagning).

Kräver BETONG-repot (assets/library) bredvid och ffmpeg.
